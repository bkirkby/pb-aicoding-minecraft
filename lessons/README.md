# Lessons

A program by [Pheirce Bytes](https://www.pheircebytes.com/ai-consulting), in partnership with [Bright Tomorrow](https://www.brighttomorrowmath.com/).

One Markdown file per session, numbered: `session1.md`, `session2.md`, and so on. Each one should say what the session is for, what it assumes is already done, the steps, and what the student should walk away with. Each session has a matching `talking-points<N>.md` for the instructor: short discussions to have while something is loading.

| Session | What happens |
| --- | --- |
| [0](../guides/windows-setup-guide.md) | Setup, with the instructor present: run the install script, sign in opencode, create the Modrinth instance, check everything works |
| [1](session1.md) | Describe the game to the AI, plan it together, let it build the first version |
| [2](session2.md) | Get the mod into the real game, learn the bug report formula, automate the build-and-install loop |
| [3](session3.md) | Polish: decide how each moment should feel, rewrite the dialogue by hand |
| [4](session4.md) | Run a small model locally with llama.cpp and wire the pet to it, with canned lines as the fallback |
| [5](session5.md) | The mod detects, downloads, and launches the model itself; the pet gets an editable personality and memory |
